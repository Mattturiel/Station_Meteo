# Station_Meteo

Projet de BTS CIEL option A : développement du firmware d'une station météo
connectée pour un hippodrome. La carte est basée sur un microcontrôleur
ATmega328P et transmet ses mesures en LoRaWAN vers The Things Network (TTN).

## Objectifs
- Acquérir les mesures des capteurs météo
- Traiter et formater les données
- Transmettre les données via LoRaWAN/TTN
- Optimiser la consommation énergétique (deep sleep, réveils par timer)

## Contenu du dépôt
- `planning/` : diagrammes de Gantt prévisionnel et réel
- `docs/` : documentation (à venir)
- `src/` : code du firmware (à venir)
